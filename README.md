# 文字数カウント
![test](https://github.com/mei36/robosys2026/actions/workflows/>

日本語の文章の文字数を数えるコマンドです。

## 使い方

- 標準入力から文章を読みます。
- 文字数を標準出力に表示します。


## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
