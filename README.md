# 文字数カウント

[![test](https://github.com/mei36/mojicount/actions/workflows/test.yml/badge.svg)](https://github.com/mei36/mojicount/actions/workflows/test.yml)

日本語の文章の文字数を数えるコマンドです。標準入力から文章を読み、数字を1つ出力します。

「2000字以内」「原稿用紙5枚」といった条件を、テキストファイルのまま確認できます。

```
$ echo "こんにちは 世界" | ./mojicount
7
```

## インストール

```
$ git clone https://github.com/mei36/mojicount.git
$ cd mojicount
$ chmod +x mojicount
```

## 使い方

標準入力から文章を渡します。何も指定しなければ、空白を除いた文字数を出力します。

```
$ ./mojicount < report.txt
$ cat report.txt | ./mojicount
```

オプションを付けると、ほかの数字を出力します。

| オプション | 出力する数字 |
| --- | --- |
| なし | 空白を除いた文字数 |
| `-t`, `--total` | 総文字数（空白を含み、改行を除く） |
| `-l`, `--lines` | 行数 |
| `-s`, `--sheets` | 400字詰め原稿用紙の枚数（空白を除いた文字数を400で割って、切り上げた値） |
| `-h`, `--help` | 使い方を表示する |

オプションは、同時に1つしか指定できません。

```
$ echo "こんにちは 世界" | ./mojicount -t
8
$ echo "こんにちは 世界" | ./mojicount -l
1
$ echo "こんにちは 世界" | ./mojicount -s
1
```

出力が数字だけなので、ほかのコマンドと組み合わせられます。

```
$ echo "今回は $(echo "あい う" | ./mojicount) 字です"
今回は 3 字です
```

間違った使い方をしたときは、メッセージを標準エラー出力に出して、終了ステータス 2 で終了します。標準出力には何も出しません。

## 注意

- 入力は UTF-8 のテキストを想定しています。
- 空白は、半角スペース、全角スペース、タブです。
- 文字数はUnicodeのコードポイント単位でカウントします。そのため、複数のコードポイントから構成される絵文字などは、画面上で見える文字数と一致しない場合があります。
- 行頭に句読点を置かない決まりなど、原稿用紙の細かい決まりは考えていません。
